===================================================
LifeSync - Visual Studio Code (VS Code) Project
===================================================

How to open and run this project in VS Code:

1. Extract this ZIP file onto your computer.
2. Open Visual Studio Code.
3. Click "File" -> "Open Folder..." and select the unzipped folder.
4. Press `F5` or right-click `index.html` and click "Open with Live Server".
5. LifeSync will launch automatically in your browser!

Note: No terminal commands, Node.js, or installation required!
